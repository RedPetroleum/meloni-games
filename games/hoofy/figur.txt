# Spielfigur in Schichten für die Garderobe im blauen Haus (game/garderobe.lua, game/figur.lua).
# tools/hoofy_figur.py schneidet jede Schicht auf ihre Pixel zu und schreibt sie ohne die färbbaren Pixel in
# den erzeugten Teil von sprites.txt; Lage, färbbare Flächen (als Rechtecke) und Farben nach game/figur_pos.lua.
#
#   layer NAME X Y     X, Y: linke obere Ecke der Zeilen im 12×20-Bild der Figur (wie player_down),
#                      darf negativ sein (Hüte, Umhang, große Frisuren). "." ist durchsichtig.
#   farbe ART ID ZEICHEN=RRGGBB …    Farbvariante einer Art (fhaar, foben, funten). Die Farbe, die genau der
#                      Palette in sprites.txt entspricht, ist die Grundfarbe (kein recolor).
#
# Namen: fkoerper_<ansicht>, funten_<stil>_<ansicht>, foben_<stil>_<ansicht>, fhaar_<stil>_<ansicht>,
# fhut_<stil>_<ansicht>. Ansichten: down, down_walk, up, up_walk, side, side_walk. Unterteile brauchen
# down, down_walk, side, side_walk (von hinten wie von vorn, Schritt gespiegelt; up/up_walk nur, wenn anders),
# Oberteile down, up, side, side_walk (beim Gehen von vorn/hinten gleich), Haare und Hüte down, up, side.
# Endung _b: wird vor dem Körper gezeichnet (Umhang hinter der Figur).
# Schichtfolge: _b, Körper, Unterteil, Oberteil, Haare, Hut. Zeichen: L Haare, y Haare hell, B X J Oberteil,
# T t Unterteil, Z Schuhe, K U Haut.

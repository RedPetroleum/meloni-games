# Snake

Ein kleines, direkt im Browser spielbares Snake für Meloni Games.

## Starten

[Spiel öffnen](index.html) oder die Datei `index.html` herunterladen und lokal im Browser öffnen. Es braucht keine Installation und lädt keine externen Dateien.

## Steuerung

- Pfeiltasten oder WASD: Richtung ändern
- Leertaste: pausieren/fortsetzen
- Enter: neu starten
- Touchscreen: über das Steuerkreuz oder Wischbewegungen spielen

Der Bestwert wird lokal im Browser gespeichert. Das ist ein Browser-Prototyp; direkt in der HU-086-Firmware läuft er noch nicht.
